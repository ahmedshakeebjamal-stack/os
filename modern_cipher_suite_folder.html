Modern Cipher Suite: Files and Folders (hardened)

Encrypt and decrypt files or whole folders (folder structure kept inside one encrypted archive) · 20 authenticated ciphers · Argon2id · 1 MiB authenticated chunks (reorder / truncation / tamper detected) · filename stored inside the encrypted data · header bound into every key · best-effort memory wiping · works offline in one file
Use 4+ random words or 14+ mixed characters.
Memory, passes and the PBKDF2 iteration count are stored (authenticated) inside each encrypted file, so for decryption you only need the passphrase and the salt. Each file gets its own random salt and key. 










Shortcuts: Ctrl+Enter encrypts, Ctrl+Shift+Enter decrypts, Ctrl+Shift+X wipes all fields. Cipher, memory, passes and iterations are remembered on this device (never the passphrase or salt). The whole result is held in memory before you save it, so keep files under roughly 200 MB on a phone. Folders: desktop browsers can pick or drop a whole folder. Android Chrome cannot pick folders: select all the files inside instead and tick the bundle box (sub-folder structure is not available there). Empty folders are not kept. Saved decrypted files are written to your device storage in plain form, incognito or not.
